## Contributing

Contributions are welcome! Please follow these steps:

1. Fork this repository
2. Create a feature branch (`git checkout -b add-new-tool`)
3. Add your tool to the appropriate category following the table format
4. Include: tool name, link, brief description (1–2 sentences), and pricing
5. Submit a pull request with a clear description of why the tool belongs here

**Criteria for inclusion:**
- The tool must be actively maintained (updated within the last 6 months)
- It must have a working website or repository
- It should provide genuine value to developers
- Free tools are preferred, but excellent paid tools are welcome

For detailed reviews and comparisons of tools, visit [devtools-pick.vercel.app](https://devtools-pick.vercel.app).
